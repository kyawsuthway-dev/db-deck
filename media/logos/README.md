Database logos from [Simple Icons](https://simpleicons.org) 16.38.0 (CC0-1.0), used only to name each database.
`-light` files use the brand color, `-dark` files a lighter mix of it for dark themes.
MySQL's is cropped to the dolphin (its full icon includes the wordmark).
Used by the Connections view (`DbKind.logo`) and the connection form.
`-connected` files add a green dot in the bottom-right corner (the Connections view's "connected" sign).

SQL Server and Azure SQL have no logo in Simple Icons (Microsoft's logos were removed), so they use a neutral
database icon instead of the trademark: Tabler Icons' filled `database` (3.51.0, MIT), in SQL Server red
(`#CC2927`, dark `#F06B65`) and Azure blue (`#0078D4`, dark `#3A96DD`).

Oracle's logo also needs a license from Oracle (its trademark guidelines), so Oracle uses the same Tabler `database`
icon in Oracle red (`#C74634`, dark `#F0826E`).
