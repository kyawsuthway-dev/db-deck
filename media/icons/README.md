Connections tree icons from [Tabler Icons](https://tabler.io/icons) 3.51.0 (MIT, © Paweł Kuna), outline style.
Each kind has a fixed color (tree icons are images and can't follow the theme's text color):
`-light` files use the darker shade for light themes, `-dark` files the lighter one for dark themes.
Width and height are set to 16; the paths are Tabler's, unchanged.
